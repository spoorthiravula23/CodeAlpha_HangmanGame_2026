# CodeAlpha_HangmanGame_2026
Python Hangman Game for CodeAlpha Intership
CodeAlpha Hangman Game

Project Description

This is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Internship.

How to Play

- The computer randomly selects a word.
- The player guesses one letter at a time.
- Correct guesses reveal the letters.
- Incorrect guesses reduce the available chances.
- The player gets a maximum of 6 wrong guesses.

Technologies Used

- Python
- Random module
- Loops
- Conditional statements
- Lists and strings

How to Run

1. Install Python.
2. Open the project in VS Code.
3. Run the command:

"py hangman.py"
